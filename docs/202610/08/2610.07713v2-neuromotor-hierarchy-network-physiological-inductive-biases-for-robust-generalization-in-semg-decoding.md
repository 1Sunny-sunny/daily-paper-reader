## 摘要
表面肌电（sEMG）为运动解码和人机交互提供了一种可穿戴、无创的神经肌肉活动接口。群体规模解码仍然困难，因为sEMG与神经肌肉活动之间的关系因用户和会话而异，而任务相关动态跨越多个通道和多个时间尺度。从任务标签中学习波形到输出的映射，使记录变异与协调运动活动之间的区别未被显式刻画。我们提出了神经运动层级网络（NHN），该网络通过任务监督学习紧凑的潜在神经运动状态，以表示任务相关的神经肌肉协调。NHN通过受神经运动组织启发的层级结构来构建这一潜在状态。它在保留相对强度的同时自适应调整记录统计特性。其时空编码器采用参数高效的通道交互，并利用多时间尺度历史对特征进行调制。所得特征产生已学习运动基元的候选激活，这些激活经过时间整合和连续加权形成状态。理论分析刻画了NHN核心机制的效率、时间行为和优化特性。我们在emg2pose上的连续手部姿态估计和emg2qwerty上的触摸打字识别两个任务中评估该架构。在emg2pose上，与Hadidi等人最佳任务特定变体相比，NHN在所有三个泛化划分的回归和跟踪任务中，将用户平均角度误差降低了0.52%至2.84%，同时参数减少了48.42%至48.51%。在emg2qwerty上，与SplashNet-Upscale相比，NHN在零样本条件下将束搜索字符错误率降低了19.40%，微调后降低了30.42%，参数减少65.86%。基于生理学引导的潜在神经运动状态推断支持参数高效的sEMG解码。

## Abstract
Surface electromyography (sEMG) provides a wearable, noninvasive interface to neuromuscular activity for movement decoding and human-computer interaction. Population-scale decoding remains difficult because the relationship between sEMG and neuromuscular activity varies across users and sessions, while task-relevant dynamics span channels and multiple timescales. Learning waveform-to-output mappings from task labels leaves the distinction between recording variability and coordinated motor activity implicit. We introduce the Neuromotor Hierarchy Network (NHN), which learns a compact latent neuromotor state from task supervision to represent task-relevant neuromuscular coordination. NHN constructs this latent state through a hierarchy inspired by neuromotor organization. It adapts recording statistics while preserving relative intensity. Its spatiotemporal encoder uses parameter-efficient channel interactions and modulates features with multi-timescale history. The resulting features yield candidate activations of learned motor primitives, which are temporally integrated and continuously weighted to form the state. Theoretical analysis characterizes the efficiency, temporal behavior, and optimization of NHN's core mechanisms. We evaluate the architecture for both continuous hand-pose estimation on emg2pose and touch-typing recognition on emg2qwerty. On emg2pose, NHN reduces user-averaged angular error by 0.52% to 2.84% across all three generalization splits in both Regression and Tracking relative to Hadidi et al.'s best task-specific variants, using 48.42% to 48.51% fewer parameters. On emg2qwerty, NHN reduces beam-search character error rate by 19.40% zero-shot and 30.42% after fine-tuning relative to SplashNet-Upscale, using 65.86% fewer parameters. Physiology-guided inference of a latent neuromotor state supports parameter-efficient sEMG decoding.

## 2. 论文提出的方法论

### 2.1 核心思想

- 受神经运动组织层级启发，将 sEMG 解码流程设计为：
  - **测量适配**：调整记录相关的波形统计，同时保留相对强度；
  - **时空编码**：提取跨通道、多时间尺度的协调证据；
  - **潜在状态构建**：将特征组织为若干“运动基元”的非负候选激活，再通过时间整合和连续加权形成紧凑潜在神经运动状态；
  - **任务预测**：由任务特定的预测头完成姿态估计或字符序列识别。

### 2.2 关键组成部分与算法流程

- **测量适配与强度保留**
  - 对每个通道计算因果窗口内的对数标准差，并对其累积均值做中心化，得到相对强度线索 \(q\)。
  - 采用部分白化 \(W(x)\)：在通道级归一化和联合白化之间进行插值，正则项由通道方差计算，避免主成分旋转。
  - 波形路径将原始信号、累积通道归一化结果和部分白化结果结合，学习残差强度 \(\eta_d,\eta_w\) 和固定尺度 \(s_0\)。
  - 通过该适配保留输入维度和相对强度，适应电极采样、组织和滤波造成的记录差异。

- **时空编码器**
  - 使用时间-深度可分离（TDS）块提取时序特征。
  - 每个 TDS 块内部：
    - 先进行深度可分离时间卷积；
    - 再进行“局部-全局混合”：局部采用共享权重的环形宽度 \(k\) 卷积，全局采用低秩投影连接远距离特征组，并用 GELU 和可学习门 \(\gamma_r\) 控制。
  - 多时间尺度上下文调制：
    - 用 \(M\) 个不同学习时间常数 \(\tau_m\) 的状态 \(s^{(m)}\) 对特征进行因果累积；
    - 将多个上下文状态拼接后通过 \(g_a\) 生成残差增益，以乘性方式调制当前特征：
      \[
      f_t = u_t \odot \left[1+\tanh(g_a([s^{(1)}_t;\dots;s^{(M)}_t]))\right]
      \]

- **潜在神经运动状态构建**
  - **非负候选驱动**：对特征做点式仿射映射、层归一化和 Softplus，得到非负候选驱动
    \[
    d_t=\text{Softplus}(\text{LN}(g_d(f_t)))\in\mathbb{R}^N_{\ge 0}
    \]
  - **时间整合**：将候选驱动通过多条因果有限冲激响应（FIR）路径进行过滤，每条路径对应不同正几何核；输出加上恒等路径，并用 softmax 归一化路径权重。这样模仿运动神经元对不同收缩时间尺度的突触输入整合。
  - **Henneman 启发式分配**：引入学习到的招募优先级 \(\beta\)，并基于当前驱动大小计算温度 \(\theta_t\)：
    \[
    \theta_t=\max(10^{-4},\text{mean}(\text{TopK}(\bar d_t)))
    \]
    \[
    p_t=N\bar d_t\odot \text{softmax}\left(\frac{\bar d_t+\beta}{\theta_t}\right)
    \]
    该过程保留连续幅值，同时体现不同基元的不均匀参与。

- **任务特定预测头**
  - 姿态估计：自回归 LSTM 预测关节角度；
  - 打字识别：TDS + CTC 预测字符序列。

## 6. 论文的主要结论与发现

- **emg2pose**：
  - 在所有三个泛化划分（User、Stage、User × Stage）的 Regression 和 Tracking 中，NHN 的 AE 和 LD 均优于 Hadidi 等人最佳任务特定变体；
  - 相对于 Hadidi 等人的最佳变体，AE 降低 0.52% 到 2.84%；相比 vemg2pose，在 Stage 和 User × Stage 上的优势更明显；
  - NHN 使用 48.42% 到 48.51% 更少参数，35.55% 到 35.64% 更少计算。

- **emg2qwerty**：
  - 零样本 TDT 贪心 CER 相对 SplashNet-Upscale 降低 6.16 个百分点；束搜索 CER 相对降低 19.40%；
  - 微调后束搜索 CER 相对 SplashNet-Upscale Shared 降低 30.42%；
  - 参数减少 65.86%，计算减少 74.99%。

- **潜在状态组织**：
  - 姿态任务中，多个基元的相对激活与手指关节角度存在分布式关联；
  - 打字任务中，相同按键的基元激活模式比不同按键更相似；
  - 两种任务对时间历史的需求不同：姿态更依赖长上下文自适应增益，打字更依赖中时间尺度上下文和近期候选驱动。

- **分配机制的重要性**：
  - 在总激活不变的情况下，仅改变基元间的相对分配即可显著降低解码性能，说明预测头依赖的是基元激活分布，而不仅是总强度。

## 7. 优点

- **生理学归纳偏置设计清晰**：从测量适配、时空整合到运动基元分配，每一层都有神经肌肉生理学动机，而非单纯堆叠深度学习模块。
- **参数高效**：在姿态和打字任务上均以更少参数和计算量取得更好或相当的性能，适合可穿戴设备。
- **跨任务泛化**：同一 NHN 骨干架构搭配任务特定预测头，可同时处理连续回归和离散序列识别。
- **实验多样性强**：覆盖跨用户、跨阶段、跨会话、零样本和微调等多种泛化设置。
- **可解释性分析**：不仅报告性能，还分析了潜在状态与关节角度、按键模式、时间尺度偏好之间的关系。
- **消融方向明确**：通过均匀分配干预证明潜在状态内部结构的重要性。

## 8. 不足与局限

- **组件可解释性受限**：论文作者明确表示，NHN 学习到的“基元”是任务表示，并非可验证的真实生理源（如真实运动单元或肌肉协同）。
