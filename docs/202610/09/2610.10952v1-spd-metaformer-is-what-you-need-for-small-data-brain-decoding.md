## 摘要
脑信号解码具有挑战性，因为神经记录存在噪声且个体间差异较大，同时标注数据往往有限。然而，基于对称正定（SPD）流形的近期注意力模型利用协方差和连接性表示取得了强劲性能，但学习到的令牌加权贡献仍不明确。我们考察了两种代表性架构，MAtt（基于对数欧几里得几何）和 GBWAtt（基于广义 Bures-Wasserstein 几何），发现它们学习到的注意力权重在训练后仍接近均匀。我们将这一行为归因于有界相似性参数化，在原始 softmax 缩放下限制了注意力权重对比度。此外，在训练和评估过程中用均匀权重替代学习权重对平均预测性能影响甚微，同时保留了各模型原有的聚合几何。受这些发现启发，我们提出了 SPD-MetaFormer，一种基于对数欧几里得几何下均匀加权 Fréchet 聚合的无注意力架构。其主干利用测地残差更新汇总令牌，并使用共享谱前馈映射变换所有令牌，随后进行学习加权读出。令牌状态保持 SPD 值直到切空间分类。在三个脑电图基准上，SPD-MetaFormer 相对于已发表的欧几里得和流形基线取得了具有竞争力的结果。单独的匹配复现实验测试了 MAtt 和 GBWAtt 中学习加权与均匀加权。这些结果表明，在研究的短序列和有限数据场景下，精心设计的 SPD 架构可以为自适应流形注意力提供一种更简单且有效的替代方案。

## Abstract
Brain signal decoding is challenging because neural recordings are noisy and vary across individuals, while labeled data are often limited. Recent attention-based models on the symmetric positive definite (SPD) manifold have nevertheless achieved strong performance using covariance and connectivity representations, yet the contribution of learned token weighting remains unclear. We examine two representative architectures, MAtt (based on log-Euclidean geometry) and GBWAtt (based on generalized Bures--Wasserstein geometry), and find that their learned attention weights remain close to uniform after training. We relate this behavior to bounded similarity parameterizations that, under the original softmax scaling, limit attention-weight contrast. Moreover, replacing learned weights with uniform weights, throughout training and evaluation, has little effect on mean predictive performance while preserving each model's original aggregation geometry. Motivated by these findings, we introduce SPD-MetaFormer, an attention-free architecture built on uniformly weighted Fréchet aggregation under log-Euclidean geometry. Its backbone uses a geodesic residual to update a summary token and a shared spectral feedforward map to transform all tokens, followed by a learned weighted readout. Token states remain SPD-valued until tangent-space classification. Across three EEG benchmarks, SPD-MetaFormer achieves competitive results relative to published Euclidean and manifold baselines. Separate matched reproductions test learned versus uniform weighting within MAtt and GBWAtt. These results suggest that, in the short-sequence and limited-data regimes studied, carefully designed SPD architectures can provide a simpler and effective alternative to adaptive manifold attention.

## 1. 论文的核心问题与整体含义

- **研究背景**：脑信号解码（brain decoding）面临神经记录噪声大、个体间差异显著、标注数据有限且采集成本高等挑战。传统方法包括卷积解码器以及显式建模二阶统计量的方法，其中脑电（EEG）协方差矩阵、fMRI 功能连接矩阵等可视为对称正定（SPD）矩阵，并可借助 SPD 流形几何进行有意义的距离与均值计算。
- **核心问题**：近期基于 SPD 流形的注意力模型（如 MAtt、GBWAtt）虽取得较强性能，但学习到的 token 加权（attention weights）对性能的具体贡献并不清晰。论文通过受控实验检验这一贡献，发现这些模型学到的注意力权重接近均匀分布，用均匀权重替代学习权重对平均预测性能影响很小。
- **整体含义**：在短序列、小样本的脑解码场景下，注意力机制可能主要起几何平均作用，而非选择性信息路由。因此，可以设计更简单、无注意力的 SPD 架构，在保留几何感知表示与聚合的同时，达到与自适应流形注意力相当甚至更优的性能。

## 2. 论文提出的方法论

### 2.1 核心思想
- 提出 **SPD-MetaFormer**，一种无注意力、基于 SPD 流形的脑解码架构。
- 设计原则：将“局部协方差记忆 token”与“全局汇总 token”分离，通过 **均匀几何混合** 更新汇总 token，保留局部证据至最终读出阶段；在进入欧氏决策空间之前，所有 token 始终保持 SPD 值。

### 2.2 关键技术细节

- **协方差 token 构建**：
  - 使用卷积前端提取 EEG 特征图 `F`。
  - 将特征图分成若干组，对每组计算正则化协方差矩阵 `C_i = (1/(L_i-1)) * \bar{F}_i \bar{F}_i^T + εI`，作为局部记忆 token。
  - 同时构建一个观测到的全局状态 `C_s`（完整特征序列协方差或各通道组协方差的均值），作为汇总 token。
  - 通过共享的 congruence 映射 `We`（行正交）将局部与全局协方差映射到同一 SPD 空间：`X_i = We C_i We^T`，`S = We C_s We^T`。

- **均匀几何混合（token mixer）**：
  - 对每个记忆 token 施加可学习的正交基映射 `B`、值映射 `A` 和输出映射 `O`，并通过特征值截断（`R_{δv}`，δv=1e-4）保证正定性：
    `V_i = R_{δv}(A B X_i B^T A^T)`。
  - 计算变换后记忆 token 的 **均匀 Log-Euclidean Fréchet 均值**：
    `G = exp( (1/m) Σ log V_i )`。
  - 再经输出映射得 `U = O G O^T`。

- **门控测地残差更新汇总 token**：
  - 沿 Log-Euclidean 测地线在旧汇总 `S` 与记忆均值 `U` 之间插值：
    `S^{(1)} = S #_α U = exp( (1-α) log S + α log U )`，其中 `α = sigmoid(a)` 为可学习标量。
  - 记忆 token 走恒等路径 `X_i^{(1)} = X_i`。

- **共享谱前馈收缩（shared spectral shrinkage / FFN）**：
  - 对所有 token 应用同一可学习标量参数 `ρ = 0.1 exp(θ)` 的谱收缩映射：
    `Φ_ρ(M) = M + ρ * (tr(M)/d) * I`。
  - 该操作保持正定性，且不会增大谱条件数；可视为对协方差矩阵的 isotropoic shrinkage。

- **试次无关的几何读出（geometric readout）**：
  - 为每个记忆位置和汇总 token 分配可学习分数 `b_i`、`β`，经 softmax 归一化得权重 `π`。
  - 计算加权 LE Fréchet 均值：
    `P = exp( Σ π_i log X_i^{(2)} + π_{m+1} log S^{(2)} )`。
  - 该读出权重跨试次共享，仅在最终分类前混合局部与全局信息。

- **单一流形出口**：
  - 将 SPD 表示 `P` 映射到单位元切空间：`h = svec(log P)`。
  - 使用单层仿射分类器输出类别 logits：`softmax(W_h h + b_h)`。
  - 训练使用交叉熵损失，ERN 任务使用类别加权。

## 6. 论文的主要结论与发现

- **流形注意力接近均匀**：MAtt 和 GBWAtt 在训练后学到的注意力权重高度接近均匀分布（归一化熵均 > 0.9988），说明它们在所研究场景下主要执行几何平均。
- **均匀权重可替代学习权重**：在 MAtt 和 GBWAtt 中锁定均匀权重后，平均性能变化均不超过 0.36 个百分点，且所有配对区间包含零，表明内容依赖的加权未带来可测量的预测收益。
- **温度调节无法恢复注意力优势**：降低 softmax 温度可显著提高注意力对比度，但性能反而下降；经验证选择后温度调整相对均匀混合没有一致优势。
- **SPD-MetaFormer 有效**：在 MI、SSVEP、ERN 上分别取得 75.44%、70.79% 准确率/82.53% AUC，超过发布基线最高均值；在 ABIDE 上取得最高 AUC 79.14%。
- **完整 SPD 处理路径不可缺少**：卷积前端、SPD token 化、均匀几何混合、谱收缩和静态几何读出共同作用，任一环节简化（如欧几里得 MetaFormer、拼接读出、仅汇总读出）都会导致性能下降。
- **谱 FFN 提升对 token 粒度的鲁棒性**：单参数谱收缩能显著降低细粒度 token 带来的性能损失，并改善矩阵条件数。
- **总体结论**：在短序列、有限数据情境下，SPD 模型的有效性可来自几何感知的表示、变换与聚合，而不需要强选择性输入依赖加权；精心设计的简单 SPD 架构可以成为自适应流形注意力的有效替代。

## 7. 优点

- **诊断性强**：对现有流形注意力模型进行了受控干预和熵度量，直接检验注意力权重的实际贡献，为简化设计提供了实证依据。
- **架构设计简洁合理**：将局部记忆与全局汇总分离，保留 SPD 流形几何操作，仅在学习读出时引入少量可学习权重，参数效率高（例如 ERN 仅 7.5 万参数级别，远低于许多基线）。
- **实验全面且严谨**：包含跨数据集、跨模态、多种消融、温度扫描、token 粒度鲁棒性等大量实验；匹配复现和 bootstrap 区间增强了因果推断的可信度。
- **跨模态验证**：除 EEG 外还在 ABIDE fMRI 上验证，说明架构对 SPD 型神经影像表示具有通用性。
- **提出可用工具**：谱收缩模块仅用一个标量参数，显著提升对 token 粒度的鲁棒性，具有实用价值。
