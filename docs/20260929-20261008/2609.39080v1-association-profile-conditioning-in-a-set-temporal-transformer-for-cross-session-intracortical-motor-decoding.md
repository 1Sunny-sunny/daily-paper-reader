## 摘要
皮层内运动解码器在不同会话间性能下降，因为记录的单元集合发生变化，且持续存在的单元其放电与行为的关系也可能改变。大多数现有方法在每个新会话上更新网络权重，或依赖未标记活动，这不能直接揭示此类变化。我们提出 APST，一种关联特征条件化的集合-时序 Transformer，它在所有网络权重冻结的情况下适应新会话。APST 从少量带标签的校准试验中，以闭式解计算每个单元放电与行为关系的四维关联特征。这些特征用于条件化集合注意力编码器，该编码器接受任意数量和顺序的单元，后接因果 Transformer 进行流式解码。在两只猴子的留出 DANDI688 会话上，APST 的速度 $R^2$ 达到 0.78 和 0.81，而仅使用神经活动的变体为 0.40 和 0.58，且与在相同试验上微调的 RNN 相当或更优。在 FALCON 私有留出评估中，它在 M1、M2 和 H1 上分别达到 $R^2$ 为 0.65、0.42 和 0.44。

## Abstract
Intracortical motor decoders degrade across sessions because the set of recorded units changes and persisting units can alter how their firing relates to behavior. Most existing methods update network weights on each new session or rely on unlabeled activity, which does not directly reveal such changes. We present APST, an Association Profile-conditioned Set-Temporal transformer that adapts to new sessions with all network weights frozen. From a few labeled calibration trials, APST summarizes how each unit's firing relates to behavior in a four-dimensional association profile computed in closed form. The profiles condition a set-attention encoder that accepts any number and order of units, followed by a causal transformer for streaming decoding. On held-out DANDI688 sessions from two monkeys, APST reaches velocity $R^2$ of $0.78$ and $0.81$, versus $0.40$ and $0.58$ for a variant that uses neural activity alone, and matches or exceeds an RNN fine-tuned on the same trials. On FALCON private held-out evaluation, it attains $R^2$ of $0.65$, $0.42$, and $0.44$ on M1, M2, and H1.

## 1. 论文的核心问题与整体含义

- **研究背景**：皮层内运动解码旨在将神经活动映射为连续运动输出，如肢体运动学或肌电信号。然而，由于电极阵列在组织中的微小移动，跨会话（不同记录日）记录的神经单元集合会发生变化：单元可能丢失、新增或漂移；同时，持续存在的单元其放电与行为之间的关联也可能改变。
- **核心问题**：源会话（Day 0）训练的解码器在新会话（Day N）上性能下降，且固定电极索引不再对应同一神经群体。现有方法要么需要在新会话上进行梯度更新（微调），要么仅依赖无标签神经活动进行对齐，难以直接解决“持续单元放电-行为关联改变”的问题。
- **整体含义**：论文提出一种在**全部网络权重冻结**的条件下适配新会话的方法，通过少量带标签校准试验闭式计算每个单元的“关联特征”，并用于条件化解码器，从而避免部署时的反向传播和过拟合风险，同时直接利用行为标签解析单元功能身份变化。

## 2. 论文提出的方法论

论文提出 **APST**（Association Profile-conditioned Set-Temporal transformer），核心流程分为校准阶段和流式解码阶段。

- **关联特征估计（Association Profiles）**
  - 从少量带标签校准试验 $\mathcal{C}_s = \{(X_{s,j}, Y_{s,j})\}_{j=1}^{M_s}$ 中，为每个观测单元 $u$ 估计一个四维静态关联特征向量 $p_{s,u}$，整个过程为闭式解，不需要目标会话反向传播。
  - **方向调谐特征**（用于 M2 和 DANDI688 这类二维运动）：以运动方向 $\theta_{s,j}$ 为设计变量，拟合一阶谐波调谐模型：
    \[
    \hat R_{s,j,u} = b_{s,u} + a_{s,u}\cos\theta_{s,j} + d_{s,u}\sin\theta_{s,j},
    \]
    得到方向系数 $a_{s,u}, d_{s,u}$、调制深度 $\rho_{s,u}=\sqrt{a_{s,u}^2+d_{s,u}^2}$ 和基线响应 $b_{s,u}$，组合为四维特征并标准化。
  - **SVD 压缩关联特征**（用于 M1 的 16 通道 EMG 和 H1 的 7 维速度）：行为通过样本权重 $\omega_{s,t}=w_{s,t,k}$ 进入。对标准化单元响应，按每个行为状态拟合加权回归，得到关联矩阵 $A_s\in\mathbb{R}^{N_s\times K}$；再将 $A_s$ 投影到源会话池化关联矩阵的前四个右奇异向量 $V_4$ 上，得到四维特征矩阵 $P_s$。
- **特征条件化的单元身份（Unit Identity）**
  - 对每个单元，校准活动经共享线性层和 ReLU 后做试验平均，得到活动签名 $h_{s,u}$。
  - 关联特征 $p_{s,u}$ 通过 **FiLM** 调制活动签名（缩放 $\gamma$ 和偏移 $\beta$），并与 $p_{s,u}$ 拼接后送入 MLP $g$，得到单元身份 $e_{s,u}$。FiLM 输出层零初始化，使训练从纯拼接条件开始。
- **集合-时序解码器（Set-Temporal Decoder）**
  - 实时活动经 5-bin 因果卷积得到 $l_{s,u,t}$；将投影后的单元身份加到 $l_{s,u,t}$，再与 $p_{s,u}$ 拼接，经 MLP 和 LayerNorm 形成单元 token $z_{s,u,t}$。
  - 使用 **8 个可学习槽查询（slot queries）** 对单元 token 集合做多头交叉注意力，实现单元顺序置换不变，并支持任意单元数量（padding mask 处理可变 $N_s$）。
  - 聚合后的 population token 进入 **4 层 pre-LN 因果 Transformer**，每层使用局部因果窗口和可学习相对时间偏置，并通过逐层 KV 缓存约束流式解码状态。最终输出经任务特定 readout 和仅推理时使用的因果 EMA 平滑。

## 3. 实验设计

论文在多个公开数据集和基准上进行了评估：

- **数据集**
  - **DANDI688**：两只猕猴（Sub-C 和 Sub-M）的 Utah 阵列记录，解码 2D 光标速度。Sub-C：18 个源会话、6 个开发会话、6 个留出会话；Sub-M：6 个源会话、2 个开发会话、3 个留出会话。
  - **FALCON 基准**：三个任务——M1（猕猴 M1 到 16 通道上肢 EMG）、M2（猕猴 Utah 阵列到 2D 手指组速度）、H1（人类 Utah 阵列到 7 维机械臂和手部速度）。FALCON 输入为非排序阈值交叉，使用官方 EvalAI 私有留出评估。
- **对比方法**
  - 梯度无关基线：WF、RNN、SPINT（无标签少样本适应）。
  - 梯度相关适应：CycleGAN+WF、NoMAD+WF、NDT2 Multi（带标签少样本微调）。
  - 私有标签 oracle：WF、RNN、NDT2 Multi 使用私有标签训练。
  - DANDI688 上另有线性基线：WF-FSS、PCA-WF，以及 RNN-ZS（零样本）和 RNN-FT（目标会话微调）。
- **评估指标**：速度 $R^2$（方差加权）、归一化延迟、留出会话均值和标准差、held-in 与 held-out 差距（$HI-HO$）。
- **消融实验**
  - **Activity-only**：不使用关联特征，仅用活动签名条件化。
  - **Static**：使用源训练的固定身份表替代校准身份。
  - **Profile shuffle**：将关联特征在单元间随机打乱。
  - **条件化位置消融**：Identity-only（仅在 site 1 使用 profile）、Token-only（仅在 site 2 使用 profile）、APST（双位置）。

## 6. 论文的主要结论与发现

- **关联特征条件化有效**：在 DANDI688 留出会话上，APST 速度 $R^2$ 达到 0.78（Sub-C）和 0.81（Sub-M），远高于 Activity-only 变体（0.40 和 0.58），且匹配或超过微调 RNN（0.77 和 0.70）。
- **FALCON 基准表现**：APST 在 M1、M2、H1 上分别达到 0.65、0.42、0.44，超过或接近梯度相关 NDT2 Multi 和私有标签 RNN oracle，同时不牺牲 held-in 精度。
- **样本效率高**：在 8 个校准试验下，APST 即可达到与 RNN 微调 16 个试验相当的精度；Sub-M 上所有预算下均优于 RNN 微调。
- **关联特征是单元级身份而非全局摘要**：打乱 profile 后性能降至 Activity-only 以下，说明 APST 利用了每个单元特定的关联信息。
- **条件化位置**：token 级条件化（site 2）贡献了大部分收益，identity 级条件化（site 1）计算免费且起辅助作用。

## 7. 优点

- **无需目标会话反向传播**：权重完全冻结，避免部署时梯度计算和过拟合，适合临床 BCI 的快速校准需求。
- **闭式关联特征估计**：计算极低（<15k 运算），且行为标签能直接解析单元功能漂移。
- **置换不变设计**：集合注意力编码器接受任意数量和顺序的单元，天然应对跨会话单元集合变化。
- **流式因果架构**：局部因果注意力窗口和 KV 缓存约束状态，适合低延迟在线解码。
- **多维任务通用接口**：四维关联特征统一了平面方向调谐和高维 SVD 压缩，跨任务适用性较强。
- **实验对比全面**：与多个强基线（SPINT、NDT2 Multi、oracle RNN）和多种消融对比，证据较充分。

## 8. 不足与局限

- **算力与训练细节不明**：未报告训练所用 GPU、训练时长、完整模型参数量等，难以复现资源成本。
- **关联特征估计仍为人工设计**：方向调谐和 SVD 压缩分别针对二维和高维任务单独设计，源会话基底和标准化参数依赖任务类型，尚不能完全统一。
- **泛化边界未充分验证**：主要基于猕猴和人类 Utah 阵列数据，未覆盖其他电极类型（如 Neuropixels）或更长时间跨度；DANDI688 Sub-C 留出会话仅 6 个，Sub-M 仅 3 个，统计可靠性有限。
- **与无标签方法比较不完全公平**：APST 使用了带标签校准试验，而 SPINT 等无标签方法没有；作者承认此差异，但可能影响“梯度无关方法”分类下的公平性。
- **条件化位置分析仅用 FALCON dev**：未在 DANDI688 留出集上进行同样拆解，结论外部有效性有待加强。
- **实际部署限制未涉及**：未讨论校准试验数量不足（如无法获得行为标签）时的降级方案，也未分析运动想象等闭环场景中的稳定性。
