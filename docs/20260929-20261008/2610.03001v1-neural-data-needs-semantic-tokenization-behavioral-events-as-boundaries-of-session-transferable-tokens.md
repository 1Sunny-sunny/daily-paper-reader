## 摘要
胞外电生理在每次会话中记录到一组不同的神经元。神经基础模型将每个神经元和每个会话都嵌入为它们各自的标记，因此每个新会话都是它们从未见过的输入，无法泛化到新会话。针对新会话的标记器需要一种每个会话共享且携带行为信息的单元。群体活动提供了这样的单元。它在低维流形上演化，一旦会话对齐，该流形在神经元更替和跨动物间持续存在。该流形在任务事件（如刺激开始和运动开始）处发生区段切换。在每个区段内，群体处于一个状态，即它在两个事件之间所张成的流形部分，每个状态都具有自身的行为含义。我们提出基于状态的标记化（Tokenization with States, TWS），它在这些事件处对每个试次（任务的一次重复）进行分段，并将每个状态转换为群体几何的标记，不包含神经元或会话嵌入。在留出的国际脑实验室（IBL）会话上，TWS甚至能从那些不携带目标信息的区段边界解码运动，而在这些会话上预训练的逐神经元基础模型则只能达到随机水平。仅在鼠类上训练后冻结，TWS只需一个线性探针即可迁移到猕猴和Utah电极阵列。在伸手方向上——一个其边界并不定义的目标——它达到了0.23的马修斯相关系数，而仅用事件时间只能达到0.01。对于跨会话泛化，标记比其上层模型更为重要。

## Abstract
Extracellular electrophysiology records a different set of neurons in every session. Neural foundation models embed each neuron and each session into their tokens, so every new session is an input they have never seen, and they fail to generalize to it. A tokenizer for new sessions needs a unit that every session shares and that carries behavior. Population activity offers such a unit. It evolves on a low-dimensional manifold that persists across neuronal turnover and across animals once sessions are aligned. This manifold changes regime at task events such as stimulus onset and movement onset. Within each regime the population occupies a state, the part of the manifold it spans between two events, and each state carries its own behavioral meaning. We propose Tokenization with States (TWS), which segments each trial, one repetition of the task, at these events and converts every state into tokens of population geometry, with no neuron or session embedding. On held-out International Brain Laboratory (IBL) sessions, TWS decodes movement even from regime boundaries that carry no information about the target, while a per-neuron foundation model pretrained on those sessions decodes at chance. Frozen after training on mice alone, TWS transfers to macaques and Utah arrays with only a linear probe. On reach direction, a target that its boundaries do not define, it achieves a Matthews correlation of 0.23, where the event time alone achieves $0.01$. For cross-session generalization, the token matters more than the model on top.

# 论文详细总结

## 1. 论文的核心问题与整体含义

- **研究动机**：胞外电生理记录在每次会话中得到一组不同的神经元。电极位置偏移、阻抗变化和 spike sorting 差异导致神经元集合不断变化，甚至同一轨迹也会产生不同群体。因此，每个新会话对已有模型来说都是分布外输入。
- **现有模型的根本问题**：神经基础模型（如 POYO、NEDS、NDT2）将神经元身份和会话身份写入 token。由于神经元标签几乎不会跨会话重复（附录 A 验证了 IBL 中 94.7% 会话对从未在 100 μm 内接近，且无标签共享），以神经元为 token 的词汇表完全依赖会话，无法泛化到新会话。
- **领域类比**：语言模型中的 tokenization 选择决定了模型的泛化能力。逐神经元 token 类似于封闭词汇的整词模型，单时间 bin 又像单字符一样缺乏语义。因此需要一种中间粒度的、可复用的语义单元。
- **核心思想**：群体活动在低维流形上演化，该流形在刺激开始、运动开始等行为事件处切换状态。每个状态（两个事件之间群体活动张成的流形部分）携带行为含义，且不依赖神经元身份。可将其作为跨会话共享的 token 单元。
- **提出的目标**：设计一个 tokenizer，使单一解码器能在所有会话中使用，且 token 携带行为语义，不需要神经元或会话嵌入。

## 2. 论文提出的方法论：TWS

### 2.1 核心思想

**Tokenization with States（TWS）** 将每个试次按行为事件（刺激开始、首次移动）分割为 \( K=3 \) 个行为状态，每个状态将群体活动转换为 Grassmannian 子空间上的 token，从而实现跨会话共享的 token 空间。

### 2.2 关键步骤

1. **输入预处理**：对每个神经元进行 \( \log(1+x) \) 变换，并在其会话批次内做 z-score 标准化（仅使用无标签活动）。
2. **状态分割**：使用软 sigmoid 门控函数在已知事件时间处放置边界，并加入可学习偏移。公式为：
   - \( w_1(t) = \sigma\left(\frac{b_{\text{stim}} - t}{\gamma}\right) \)
   - \( w_2(t) = \sigma\left(\frac{t - \tau_1}{\gamma}\right) \cdot \sigma\left(\frac{b_{\text{move}} - t}{\gamma}\right) \)
   - \( w_3(t) = \sigma\left(\frac{t - \tau_2}{\gamma}\right) \)
   - 其中 \( \tau_1 = b_{\text{stim}} + \Delta_1 \)，\( \tau_2 = b_{\text{move}} + \Delta_2 \)，\( \Delta_1, \Delta_2 \) 为所有试次和会话共享的可训练标量。
3. **状态加权平均**：对每个状态 \( k \)，计算归一化权重 \( \bar{w}_k(t) \)，得到每神经元在该状态内的平均活动 \( \bar{x}_k \in \mathbb{R}^{N_s} \)。
4. **群体几何编码**：
   - 对每个神经元 \( n \)，通过共享编码器 \( f_{\text{coord}}(p_n) + f_{\text{act}}(\bar{x}_{k,n}) \) 将其映射到 \( \mathbb{R}^d \)。
   - 使用无位置编码的 cross-attention 聚合所有 \( N_s \) 个神经元向量，每个状态有 \( k_{\text{dim}}=2 \) 个查询向量。
   - 对每个状态的两个聚合向量做 Gram-Schmidt 正交化，得到按顺序固定的正交基，即 Grassmannian 流形 \( \text{Gr}(2, 256) \) 上的点。
5. **Token 混合与预测**：6 个 token（\( K \times k_{\text{dim}} \)）经 backbone（默认 4 层 kernel-3 卷积，也可用 Transformer、Mamba 等）混合，再经线性探针输出行为预测。

### 2.3 不变性与训练

- **排列不变性**：对神经元顺序的任意置换，每个 token 不变。证明核心在于归一化、编码器和 cross-attention 均对每个神经元独立作用或对神经元做无位置编码的求和，Gram-Schmidt 则在固定查询顺序上进行。
- **预训练**：自监督损失 \( L = L_{\text{MSE}} + \lambda_{\text{div}} L_{\text{div}} + \lambda_{\text{geo}} L_{\text{geo}} \)，包括重建状态均值、状态 token 多样性、相邻状态子空间的测地距离。50% 试次随机掩蔽一个状态，模型需从剩余状态重建掩蔽状态。
- **行为微调**：每个状态一个线性头，logit 平均后预测；回归任务使用平均 token \( \bar{h} \)。
- **超参数**：\( d=256 \)，\( K=3 \)，\( k_{\text{dim}}=2 \)，门温度 \( \gamma=2 \) bins，每试次最多 128 个单元，20 ms bin。

## 6. 论文的主要结论与发现

- **TWS 在未见会话上实现有效解码**：在 IBL 53 个 held-out 会话上，TWS 的 movement MCC 达 0.565、RT R² 达 0.402，显著优于所有基线；逐神经元模型 POYO/CEBRA/NEDS 接近随机（MCC≈0）。
- **边界定义决定的 token 容量**：边界数量与位置至关重要；随机或固定边界会使性能下降 60%–70%；但真实边界下 TWS 仍保留约三分之一的解码能力，即使边界不携带目标信息，证明其解码来自于神经活动而非仅事件时间。
- **Tokenizer 比 backbone 更重要**：相同 tokenizer 下，不同 backbone 差异 ≤5%；相同 backbone 下，TWS 比 PerceiverIO 解码更高。TWS 的嵌入中会话身份方差占 23%、行为方差占 11%，而 PerceiverIO 分别为 31% 和 1%。
- **跨物种与跨记录技术迁移**：仅在小鼠 Neuropixels 上训练的冻结 TWS，通过线性探针在猕猴 Utah array 上解码 reach direction 达到 MCC 0.232，事件时间仅 0.010；在 Steinmetz 和 NLB 上也优于训练于目标数据集的 POYO。
- **数据效率**：仅用 5 个会话的标签拟合探针，TWS 在 RT 解码上超过所有基线（包括在全部会话上训练的基线），达到约 5 倍于最佳基线的 R²。
- **行为与会话身份占据不同方向**：去除会话均值方向后，TWS 的 movement 解码几乎不变；行为解码方向与会话方向正交或相关性低；这解释了为什么 TWS 能降低会话信息但保留行为信息。

## 7. 优点

- **新颖的 tokenization 视角**：将自然语言处理中的子词 tokenizer 思想引入神经数据，以行为状态作为跨会话语义单元。
- **真正的零会话拟合**：TWS 对新会话不拟合任何参数、不需要对齐或嵌入，仅需已知任务事件时间。
