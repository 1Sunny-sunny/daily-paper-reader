## 摘要
脑电图（EEG）情绪识别是人机交互的关键接口，然而个体之间的生理差异性使得融合异构生理信号（例如脑电与眼动）这一本就困难的任务更加复杂。然而，当前主流的域适应范式大多针对单模态场景设计，无法应对多模态信号的异构性。此外，它们主要依赖特征级对齐，忽视了更根本的数据级差异，这在激进适配过程中可能损害细粒度判别信息。为弥合这两个相互关联的缺口，我们提出了基于实例的域扩展与对抗学习（IDEAL），一个将实例级课程扩展与特征级层次对抗对齐协同统一的框架。IDEAL首先引入一种多模型协同筛选机制，通过数量-质量均衡策略传播高置信度目标样本，从而在数据层面显式桥接分布差距。我们提供了理论分析，证明该实例扩展策略严格收紧了目标风险的上界。随后，一个带有角度对比约束的层次对抗网络逐步将表示从低层统计对齐到高层语义，同时保持类别可分性。在四个基准数据集上的大量实验表明，IDEAL显著优于现有最先进方法。为便于复现和未来研究，我们的源代码已在 https://github.com/WY-BCI-Club/IDEAL 公开。

## Abstract
Electroencephalography (EEG) emotion recognition serves as a pivotal interface for human-computer interaction, yet the physiological variability across individuals complicates the already challenging task of fusing heterogeneous physiological signals (e.g., EEG and eye movements). However, most prevalent domain adaptation paradigms are tailored for unimodal scenarios, failing to address the heterogeneity of multimodal signals. Furthermore, they predominantly rely on feature-level alignment, overlooking the fundamental data-level discrepancy, which risks compromising fine-grained discriminative information during aggressive adaptation. To bridge these coupled gaps, we propose Instance-based Domain Expansion and Adversarial Learning (IDEAL), a unified framework that synergizes instance-level curriculum expansion with feature-level hierarchical adversarial alignment. IDEAL first introduces a multi-model collaborative screening mechanism, which propagates high-confidence target samples to explicitly bridge the distributional gap at the data level via a quantity-quality equilibrium strategy. We provide a theoretical analysis that this instance expansion strategy strictly tightens the upper bound of the target risk. Subsequently, a hierarchical adversarial network, augmented with the angular-contrastive constraints, progressively aligns representations from low-level statistics to high-level semantics while preserving class separability. Extensive experiments on four benchmark datasets demonstrate that IDEAL significantly outperforms state-of-the-art methods. To facilitate reproducibility and future research, our source code is publicly available at https://github.com/WY-BCI-Club/IDEAL.

## 2. 论文提出的方法论

### 2.1 问题形式化与理论依据
- 将跨被试情绪识别建模为概率分布不同的域适应问题：源域 \(D_S\)（K 个被试，有标签），目标域 \(D_T\)（新被试，无标签）。
- 假设存在共享潜在子空间，希望在目标域中筛选出子集 \(C \subseteq D_T\)，满足：
  - \(C\) 与源域分布接近（亲和性）；
  - \(C\) 部分保留目标域分布（代表性）。
- 基于 Ben-David 等人理论，目标域误差上界为：
  \[
  \epsilon_T(h) \le \epsilon_S(h) + \frac{1}{2} d_{H\Delta H}(D_S, D_T) + \lambda
  \]
- **Proposition 1**：若筛选出的子集 \(C\) 满足 \(d_{H\Delta H}(C, D_T) < d_{H\Delta H}(D_S, D_T)\)，则扩展后的源域 \(D_S^* = D_S \cup C\) 会严格缩小域分歧，从而收紧目标误差上界。

### 2.2 Stage 1：实例级课程扩展（Instance-Level Curriculum Expansion）
- 使用 **3 个异构观察器**：随机森林、极端随机树、CatBoost。
- 每个观察器使用 3 种输入视图：EEG-only、eye-only、拼接特征，聚合权重为 \(\{0.3, 0.3, 0.4\}\)。
- 对目标样本 \(x_j\) 计算聚合预测 \(P_{agg}(x_j)\) 和共识分数：
  \[
  Cons(x_j) = \max_k [P_{agg}(x_j)]_k
  \]
- 按共识分数降序排序，选择阈值 \(t\) 下的比例 \(r(t)\)。
- 优化目标：
  \[
  J(t) = \alpha \cdot Cons_{min}(t) + (1-\alpha) \cdot (r(t) - r(t)^2)
  \]
  其中 \(\alpha = 1 - u\)，\(u\) 为目标样本共识均值，用于自适应权衡数量与质量。
- 最终扩展源域为 \(D_S^* = D_S \cup C_t\)，从数据层面显式缩小分布差距。

### 2.3 Stage 2：特征级层次适配网络
- **多视角嵌入与注意力融合**：
  - 对每个模态生成 \(V\) 个并行视图 \(e_j = xW_j + b_j\)；
  - 门控向量 \(g = \sigma(xW_{gate} + b_{gate})\) 动态加权视图；
  - 堆叠后通过注意力融合得到紧凑特征 \(Z_{eeg-a}, Z_{eye-a}\)。
- **层次特征交互**：
  - **模态内 Transformer**：独立处理 EEG 和眼动特征，建模长程依赖，输出 \(Z_{eeg-b}, Z_{eye-b}\)；
  - **跨模态 Mix-Transformer**：拼接两个模态特征，动态挖掘互补信息，输出深度融合特征 \(Z_c\)。
- **判别性流形学习**：
  - 对比损失 \(L_{contrast}\)：模态内 InfoNCE + 跨模态相似性对齐；
  - ArcFace 角度间隔损失 \(L_{arc}\)：增强类内紧凑性与类间可分性；
  - 总分类分离损失 \(L_{cs} = L_{contrast} + L_{arc}\)。
- **层次对抗对齐**：
  - 三个域判别器 \(D_a, D_b, D_c\) 分别对应浅层、中层、深层特征；
  - 使用梯度反转层（GRL）联合优化；
  - 损失 \(L_{domain} = \sum_{l} \eta_l \mathbb{E}_x[-\log(D_l(h_l))]\)，权重 \(\eta = \{0.2, 0.3, 0.5\}\)。
- **总目标**：
  \[
  J = L_{cls} + \lambda_1 L_{cs} + \lambda_2 L_{domain}
  \]
  其中 \(\lambda_1 = 0.3, \lambda_2 = 0.5\)。

## 3. 实验设计

### 3.1 数据集
- **SEED**、**SEED-IV**、**SEED-V**、**SEED-VII** 四个公开多模态情绪数据集。
- 每个数据集包含 EEG 和眼动信号，情绪类别数分别为 3、4、5、7。
- 所有特征按被试和会话做 Z-score 标准化。

### 3.2 实验方案
- **留一被试交叉验证（LOSO）**：
  - **Intra-Session LOSO**：同一会话内，一个被试作为目标域，其余被试作为源域；
  - **All-Session LOSO**：被试的所有会话聚合为目标域，其他所有被试为源域。
- 报告平均准确率和标准差。

### 3.3 对比基线
- **经典迁移学习方法**：DANN、JDA、MWACN；
- **多模态 SOTA 方法**：CFDA-CSF、MMDA、CMSLNet、MHESA、CSMM、CMGNN、DCCA-AM、MACDB、CoDF-Net、MSBLS、RHPRNet 等。
- 所有方法采用相同的数据划分协议以保证公平性。

### 3.4 训练细节
- Stage 1 筛选高置信目标样本 \(M\)；
- Stage 2 随机采样源域样本数 \(N = \min(\max(1500, N_S \cdot M), 3000)\)，与 \(M\) 个目标样本联合训练。

## 6. 论文的主要结论与发现

- **性能优势**：
  - Intra-Session：SEED 平均准确率 **95.69%**，SEED-IV **93.16%**，SEED-V **94.75%**；
  - All-Session：SEED **94.31%**、SEED-IV **86.79%**、SEED-V **88.13%**；
  - 在多个数据集上显著超越 SOTA 方法，且标准差更低，稳定性更强。
- **模块有效性**：
  - 移除域扩展或层次对抗对齐会导致最大性能下降，说明数据级与特征级联合适配的重要性；
  - 层次对抗优于单层 DANN，证明多尺度对齐必要性；
  - ArcFace 与对比损失协同增强判别性。
- **理论验证**：
  - 在绝大多数被试上，筛选子集满足 \(d_{H\Delta H}(C, D_T) < d_{H\Delta H}(D_S, D_T)\)，验证了 Proposition 1；
  - 自适应阈值

- **自适应阈值策略**能够根据目标域样本的聚合共识均值自动调节筛选比例，在伪标签质量与样本数量之间取得动态平衡。相比固定阈值，该机制在不同会话、不同目标被试上表现出更强的适应性和稳定性，避免了因数据集分布差异导致的筛选过度或不足问题。
- **收敛分析**：Proxy A-distance 随训练迭代逐步下降，说明源域扩展和层次对抗对齐共同降低了跨域分布差异，验证了 IDEAL 在优化过程中不断收紧域间距离。
- **可视化结果**：UMAP 投影显示，经过 IDEAL 对齐后，源域与目标域的特征分布高度重叠，且不同情绪类别的聚类边界更加清晰，进一步支持了数据级扩展与特征级对齐的联合效果。

## 7. 论文的主要创新点与贡献

1. **提出 IDEAL 统一框架**：首次在面向多模态情绪识别的跨被试域适应中同时引入数据级实例扩展和特征级层次对齐，形成从数据分布到特征空间的联合适配机制。
2. **理论保证**：基于 Ben-David 等人的域适应理论，给出 Proposition 1，证明通过筛选与源域分布接近且保留目标域代表性的子集，可以严格收紧目标域误差上界，为实例级课程扩展提供了理论依据。
3. **多尺度层次对齐与判别性增强**：设计模态内 Transformer、跨模态 Mix-Transformer 以及三层域判别器，实现浅层、中层、深层特征的层次对抗对齐；同时引入对比损失与 ArcFace 角度间隔损失，在对抗对齐过程中保留细粒度判别信息，缓解负迁移。
4. **自适应课程扩展机制**：使用三个异构观察器和三种输入视图生成共识分数，并通过自适应阈值平衡样本数量与伪标签质量，避免固定阈值在不同数据集上的次优问题。
5. **充分的实验验证**：在四个 SEED 系列多模态情绪数据集上，采用留一被试跨验证，从主实验、消融、敏感性、理论条件验证、收敛性和可视化等多角度验证了方法的有效性与可解释性。

## 8. 局限性与未来方向

- **计算成本未明确**：论文未报告 GPU 型号、训练时长、参数量等具体算力信息；Stage 1 的预计算会带来较高的离线开销，可能限制在资源受限设备上的部署效率。
- **数据集同质性较强**：所有实验均基于 SEED 系列数据集，被试群体、采集设备和实验范式相对一致，跨文化、跨设备、跨年龄段的泛化能力尚未得到验证。
- **对比基线覆盖不完整**：部分 SOTA 方法（如 CMSLNet、MHESA、CSMM 等）未在所有数据集或所有协议上进行完整对比，可能影响公平性判断。
- **在线与增量场景未涉及**：当前框架假设源域和目标域批量可用，未讨论在线学习、增量域适应或类别增量等实际部署中常见的场景。
- **伪标签误差累积风险**：Stage 1 筛选虽通过共识机制降低噪声，但不可完全避免错误伪标签，尤其在高类别数（如 SEED-VII）下可能存在误差传播。
- **未来工作**可聚焦于：轻量化网络设计以降低计算开销；引入更多异质数据集进行跨库泛化验证；探索在线、无源域或类别增量的域适应方案；以及结合可解释性分析进一步理解 EEG 与眼动模态的互补机制。
